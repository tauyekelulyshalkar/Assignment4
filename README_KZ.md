## Тапсырар алдында

Код пен репорт дайын. GitHub репозиторийін жасау және сілтемесін репорттың бірінші бетіне енгізу қалды. Репозиторий бұл пакетпен автоматты түрде жасалмайды.

1. GitHub-та өз аккаунтыңа кір.
2. New repository таңда. Мысалы, атауы: `Assignment4_Forms_Validation`.
3. Репозиторийді құрғаннан кейін Add file → Upload files таңда.
4. `index.html`, `task1.html`, `task2.html`, `task3.html`, `style.css` және `assets` папкасын жүкте. Папка құрылымын сақта.
5. Commit changes батырмасын бас.
6. Ашылған нақты репозиторийдің URL мекенжайын көшір.
7. Word репорттың бірінші бетіндегі GitHub repository URL жолына қойып, файлды сақта.
8. Moodle-ға `Assignment4_Shalkar_Tauyekeluly.docx` файлын тапсыр. Қорғауға дайындал: тапсырмада қорғау міндетті.

## Формалардың жұмыс шегі

Бұл — HTML және CSS бойынша оқу тапсырмасы. Формалар өрістерді тексереді. Нақты билет сататын, хакатонға тіркейтін немесе кафе брондайтын сервер жоқ. Барлық формаларда POST көрсетілген; нақты жоба үшін `action` адресіне сервер endpoint-ін қою қажет. Жарамсыз мән енгізіп, Submit бассаң, браузер оны тоқтатады. Толық дұрыс мәндерді жібергенде сервер жоқ болғандықтан нақты тапсырыс жасалмайды. Шынайы құпиясөзіңді енгізбе.

## Қорғауға қысқа жауаптар

**Bootstrap не үшін керек?** Grid пен дайын form-control, form-select, form-check сияқты кластар береді. Өз CSS файлым Bootstrap-тен кейін қосылып, сыртқы көріністі өзгертеді.

**Неге `col-12 col-md-6`?** Кішкентай экранда өріс 12 бағанның бәрін алады. 768 px-ден бастап 6 баған, яғни жолдың жартысын алады.

**Неге телефонда Find trains жоғарыда?** HTML ішінде Clear бірінші тұр. `flex-column-reverse` шағын экранда визуалды ретті кері аударады. `flex-md-row` үлкен экранда көлденең ретті қайтарады. Tab реті HTML ретімен қалады.

**Неге Clear шынымен бәрін босатады?** `type="reset"` бастапқы мәндерге қайтарады. Бастапқы input мәндері бос, radio және checkbox-та checked жоқ, select-тің бастапқы option мәні бос.

**`id` пен `name` айырмашылығы қандай?** `id` label және CSS сияқты байланыстарға керек; бір бетте бірегей болуы тиіс. `name` форма жібергенде өрістің кілті болады. Name болмаса, мән форма деректеріне кірмейді.

**`for` не үшін керек?** Label-дің for мәні input-тың id мәніне тең. Label-ді басқанда input фокус алады және экран оқитын құрал оның атауын түсінеді.

**`required` не істейді?** Міндетті өрістің бос болуына жол бермейді. Checkbox үшін белгі қойылуын, radio тобында бір таңдау болуын талап етеді.

**Неге уақыттың `step="1800"`?** Time input-та step секундпен беріледі. 30 минут = 1800 секунд. `min="09:00"` бойынша 09:00, 09:30, 10:00, 10:30 және т.б. мәндер өтеді.

**Неге team size үшін `step="1"`?** Қатысушылар саны бүтін сан болуы керек. `min="1" max="4" step="1"` тек 1, 2, 3, 4 мәндерін өткізеді.

**Неге GitHub өрісі бос болса қабылданады?** Онда required жоқ. Толтырылса, `type="url"` толық URL синтаксисін тексереді. Аккаунттың шынымен бар-жоғын тексермейді.

**`minlength` пен `maxlength` не істейді?** Мәтіннің ең аз және ең көп ұзындығын белгілейді. Maxlength шегінен артық таңбаларды браузер енгіздірмейді. Minlength-ті тексеру үшін мәтінді нақты енгізу керек; тек JavaScript арқылы value орнату әрқашан бірдей нәтиже бермейді.

**Неге қателер бірден шықпайды?** Қызыл стильге `:invalid` емес, `:user-invalid` қолданылған. Браузер пайдаланушының әрекетінен кейін қате күйді көрсетеді. Жіберу әрекеті де қате күйді көрсетуі мүмкін.

**Неге seating radio-ларында бірдей name?** Бір name оларды бір топқа біріктіреді. Сондықтан Inside пен Terrace-тің тек біреуі таңдалады. Олардың value мәндері әртүрлі.

**Неге Reserve div емес, button?** Native button Tab арқылы фокус алады, Enter немесе Space арқылы іске қосылады. `type="submit"` форманы native validation-нан өткізеді.

**Телефонның type="tel" түрі нөмір форматын тексере ме?** Өздігінен қатаң форматты тексермейді; көбіне телефонға ыңғайлы пернетақта береді. Бұл тапсырмада телефон үшін required талабы орындалған.

**Неге әр университет email-і қабылдануы мүмкін?** Тапсырма тек valid email сұрайды. `type="email"` синтаксисті тексереді; университет доменімен шектейтін қосымша ереже қосылмаған.

**Неге Return автоматты required болмайды?** Тапсырма Return өрісін міндетті деп көрсетпейді. Бір радиоға байланысты required күйін динамикалық өзгерту бұл HTML-only нұсқасына қосылмаған.
